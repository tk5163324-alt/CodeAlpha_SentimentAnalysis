# 📊 CodeAlpha Sentiment Analysis

## 📌 Project Overview

This project performs sentiment analysis on customer reviews using Python and VADER Sentiment Analysis.

The system analyzes customer review text and classifies each review as:

- 😊 Positive
- 😐 Neutral
- 😞 Negative

It also generates visualizations and an interactive Streamlit dashboard.

---

## 🎯 Objectives

- Analyze customer reviews
- Calculate sentiment scores
- Classify reviews into sentiment categories
- Visualize sentiment distribution
- Create an interactive dashboard
- Save the analyzed results for further analysis

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- VADER Sentiment
- Plotly
- Streamlit
